# Python Analysis

## Bank Marketing Campaign Analytics

Python was used for exploratory data analysis, statistical analysis, visualization, and deeper interpretation of the Bank Marketing campaign dataset.

The Python analysis complements the SQL analysis and Power BI dashboard by exploring customer characteristics, campaign behavior, subscription patterns, and important relationships within the dataset.

## Analysis Performed

### 1. Data Loading & Inspection

- Loaded the cleaned Bank Marketing dataset using Pandas
- Inspected dataset dimensions and data types
- Reviewed categorical and numerical variables
- Checked for missing and duplicate records
- Validated the cleaned dataset

### 2. Exploratory Data Analysis

The analysis explored:

- Subscription distribution
- Customer age groups
- Job categories
- Education levels
- Marital status
- Housing and personal loans
- Contact methods
- Campaign contact frequency
- Previous campaign outcomes
- Monthly campaign performance

### 3. Conversion Analysis

Python was used to calculate and visualize subscription conversion rates across important business dimensions, including:

- Age groups
- Job profiles
- Education
- Marital status
- Contact method
- Campaign frequency
- Previous campaign outcome
- Monthly trends

### 4. Statistical Analysis

Statistical analysis was used to identify meaningful patterns and understand relationships between campaign variables and subscription outcomes.

The analysis focused on:

- Conversion rate comparisons
- Customer segment behavior
- Campaign contact effectiveness
- Previous campaign performance
- Economic indicator patterns

### 5. Business Insights

The Python analysis helped identify several important patterns:

- Overall subscription conversion was **11.27%**.
- Previous campaign success was associated with the strongest observed conversion.
- Repeated campaign contacts generally showed declining conversion.
- Cellular contact performed better than telephone contact.
- Conversion varied considerably across customer and campaign segments.
- Economic indicators provided additional context for campaign performance.

## Python Libraries

The analysis uses commonly used data analytics libraries:

- **Pandas** — Data manipulation and analysis
- **NumPy** — Numerical operations
- **Matplotlib** — Data visualization
- **Seaborn** — Statistical visualization
