# Dashboard Screenshots

This folder contains screenshots of the **Bank Marketing Campaign Analytics** Power BI dashboard.

The screenshots provide a visual overview of the interactive dashboard and its four analytical pages.

## Dashboard Pages

### 1. Overview

Provides a high-level summary of campaign performance, including:

- Total Contacts
- Successful Subscriptions
- Conversion Rate
- Previous Contacts
- Average Call Duration
- Monthly Conversion Trends
- Conversion by Contact Type
- Conversion by Age Group
- Previous Campaign Outcome
